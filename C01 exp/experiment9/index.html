Experiment 9

Observing Internet Protocols Using Browser Developer Tools

Aim

To observe URL, Protocol, Request Method, Status Code, File Type, Size and Loading Time using the Browser Developer Tools Network tab.

Procedure

  1. Open any website in Google Chrome.
  2. Press F12 to open Developer Tools.
  3. Select the Network tab.
  4. Refresh the webpage.
  5. Observe the network requests.
  6. Record URL, Protocol, Method, Status Code, File Type, Size and Loading Time.

Sample Observation

Parameter Value
URL https://www.google.com
Protocol HTTPS
Request Method GET
Status Code 200 OK
File Type document
Size 18 KB
Loading Time 120 ms

Result

The network request details were successfully observed using Browser Developer Tools.
