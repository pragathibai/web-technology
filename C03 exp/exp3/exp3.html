Intrinsic vs addEventListener()

Both buttons do the same thing, but are wired up differently.

  • Intrinsic (onclick="…") — handler lives inside the HTML tag. Quick to write, but mixes JS logic into markup and only allows one handler per event.
  • addEventListener() — handler lives in the JS file, kept separate from HTML. Supports multiple listeners on the same element/event, and is the modern best practice.
